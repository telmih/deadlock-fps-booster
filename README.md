# deadlock-fps-booster
Deadlock FPS optimization for mid to low end systems. November 2026
Deadlock FPS Config is aimed at lowing the graphics settings as much as possible while keeping the competitive integrity for ranked play


HOW TO USE

Download the project to your computer as zip

Extract project to folder

Open the setup file

With the deadlock config, you can potentially see a ~30% improvement in 1% lows and ~40% average FPS gain on most low to mid range systems.
"How do I find a command in the config"
Press ctrl+f in your text editor and type in the command you want to change.

"How do I restore a value to default"
Removing the command entirely is the easiest way

"How do I change my fov" r_aspectratio citadel_camera_hero_fov

Adjust these two values to your liking.
"The config broke this patch"
The gameinfo.gi gets overwritten in some patches, even small ones. You may need to manually replace it again.

"My game is crashing" You may have to completely delete and reinstall the game by uninstalling and making sure there are no leftover files from previous configs or mods. (some mods replace original files and cause files to persist when doing a simple Steam Uninstall. Make sure to delete the Deadlock file ENTIRELY. - Example
